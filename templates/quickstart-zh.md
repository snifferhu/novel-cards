## 主线六步（最小闭环）

走通「建卡 → 成稿 → 复盘」的最小创作闭环，只需以下六步：

| 步骤 | 做什么 | 调用技能 | 产物 |
|---|---|---|---|
| 1 | 收纳入手素材（口述灵感 / 粘贴文本 / 网页摘抄） | `nc-素材` | `res/inbox/` + 语料卡 |
| 2 | 建核心卡片：角色 / 道具 / 场景 / 桥段 | `nc-角色` / `nc-道具` / `nc-场景` / `nc-桥段` | `cards/` 下各类型卡 |
| 3 | （可选）给关键桥段绑积木模块，组装触发关系 | `nc-积木` | `cards/modules/md-*.md` |
| 4 | 出正文初稿（按篇幅档位） | `nc-成稿 --length short/mid/long` | `manuscript/chapter-*.md` 提案 |
| 5 | 校阅调整（设定一致性 / 节奏 / 伏笔冲突） | `nc-校阅`（内置 `nc-节奏`） | 审计意见书（只出建议） |
| 6 | 沉淀经验、回流素材库，开启下一轮构思 | `nc-复盘` | `reflections/rf-*.md` |

> **提案制**：以上每一步 AI 都只输出完整 Markdown 提案到对话，**你确认后自行落盘**；
> AI 绝不直接写卡 / 写正文。

## 进阶扩展（按需启用）

主线跑顺后，可按需解锁以下能力（均支持中文 + 英文别名调用）：

### 叙事建模增强

- `nc-动向` — 刻画角色性格/心智倾向的滑动标尺（每次变动绑定具体桥段推手）
- `nc-姿态` — 角色招牌动作库（内核 + 环境插槽 + 多视角模板）
- `nc-感官标记` — 声音/气味/光影等标志性氛围信号
- `nc-伏笔` — 长线伏笔预埋与回收登记（短篇默认关闭）
- `nc-快照` — 时间锚点全局状态切片（长篇群像优先）
- `nc-势力` / `nc-暗线` — 多方势力网络 / 隐秘叙事链路（长篇默认开启）

### 创作迭代分支

- `nc-研判` — 对少量资产做单点推演，出方案 A/B/C（**只出建议报告，不改卡**）
- `nc-编排` — 批量迭代/扩写/重构整条故事线（**先出计划交你审核再执行**）

### 深度打磨与校验

- `nc-量化` — 张力/爆点/信息载荷量化指标
- `nc-词频` — 词频向量 + 感官均衡约束（配合成稿）
- `nc-图谱` — 渲染叙事森林时序图 / 关系图 / 动线链路图
- `nc-守卫` — 隐私 + 合规内容扫描（分发前使用）

### 归档导出与维护

- `nc-定稿` — 工程快照归档、打锁定标记
- `nc-导出` — 跨平台导出 PDF / Word
- `nc-更名` — 改书名 / 全局代号重命名（**先预览后替换，不动原始素材**）
- `nc-检索` / `nc-清洗` / `nc-注册` — 检索资产 / 素材降噪 / 注册自定义类型

## 长短篇差异
