## Mainline Six Steps (Minimal Loop)

Run the minimal "build cards → draft → retrospect" creative loop in six steps:

| Step | What to do | Skill | Output |
|---|---|---|---|
| 1 | Ingest raw material (spoken ideas / pasted text / web excerpts) | `nc-素材` | `res/inbox/` + corpus card |
| 2 | Build core cards: character / item / scene / plotpoint | `nc-角色` / `nc-道具` / `nc-场景` / `nc-桥段` | typed cards under `cards/` |
| 3 | (optional) Bind key plotpoints to module blocks, assemble trigger relations | `nc-积木` | `cards/modules/md-*.md` |
| 4 | Generate a first draft (by length tier) | `nc-成稿 --length short/mid/long` | `manuscript/chapter-*.md` proposal |
| 5 | Review & adjust (setting consistency / rhythm / foreshadow conflicts) | `nc-校阅` (embeds `nc-节奏`) | audit opinion sheet (advice only) |
| 6 | Distill lessons, feed back into the material pool, start the next round | `nc-复盘` | `reflections/rf-*.md` |

> **Proposal system**: at every step the AI only outputs a complete Markdown proposal
> into the chat — **you confirm and save it yourself**. The AI never writes cards or
> prose directly.

## Advanced Extensions (Enable On Demand)

Once the mainline runs smoothly, unlock these on demand (all support Chinese + English
aliases):

### Narrative Modeling Enhancements

- `nc-动向` — a sliding scale for a character's personality/mental tendency (each shift binds a concrete plotpoint as the driver)
- `nc-姿态` — signature-action library (core + environment slots + multi-view templates)
- `nc-感官标记` — signature atmosphere signals (sound/scent/light)
- `nc-伏笔` — long-line foreshadow setup & payoff registration (off by default in short)
- `nc-快照` — time-anchor global state slice (preferred for long ensemble casts)
- `nc-势力` / `nc-暗线` — faction networks / hidden narrative threads (on by default in long)

### Creative Iteration Branches

- `nc-研判` — single-point reasoning over a few assets, emits plans A/B/C (**report only, never edits cards**)
- `nc-编排` — batch iterate/expand/restructure an entire storyline (**plan is reviewed by you before execution**)

### Deep Polish & Validation

- `nc-量化` — tension/climax/info-payload metrics
- `nc-词频` — word-frequency vector + sensory-balance constraints (pairs with drafting)
- `nc-图谱` — render narrative-forest timeline / relation / track-link graphs
- `nc-守卫` — privacy + compliance content scan (use before distribution)

### Archival, Export & Maintenance

- `nc-定稿` — project snapshot archival, lock marker
- `nc-导出` — cross-platform PDF / Word export
- `nc-更名` — rename book title / global codename (**preview first, then replace; never touches raw material**)
- `nc-检索` / `nc-清洗` / `nc-注册` — query assets / denoise material / register custom types
