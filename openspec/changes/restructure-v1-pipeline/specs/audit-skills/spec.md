# Spec Delta

## Purpose

定义三个校验审计技能（`nc-校阅` / `nc-节奏` / `nc-守卫`）的审计维度、告警分级、豁免规则与输出契约。核心铁律：审计类技能只输出意见，绝不自动修改、删除文稿。

## ADDED Requirements

### Requirement: 审计技能只出意见

`nc-校阅` / `nc-节奏` / `nc-守卫` MUST 只输出意见书，绝不自动修改、删除任何文稿或卡片内容；所有发现以「建议」形式呈现，由作者自行决定是否采纳并手动修改。

#### Scenario: 审计不改稿
- **WHEN** `nc-校阅` 发现某桥段角色动机缺失
- **THEN** 输出意见「第 X 章 Y 桥段：角色行为缺乏前置欲望铺垫，建议在 pp-xxx 补充动机节点」，不直接编辑该卡

### Requirement: nc-校阅 审计维度

`nc-校阅` SHALL 按以下维度执行叙事审计（产出 `review-xxx.md` 可读意见书 + `review-xxx.json` 结构化清单）：

1. **设定一致性审计（最高优先级）**：角色/道具/pose 定义与桥段、快照使用是否冲突；世界观、势力、玄幻规则是否自洽
2. **动线与状态链路审计**：感知/抽象动线前后状态跳变无过渡；伏笔丢失/回收太早太晚/逻辑矛盾；角色获取信息是否合理
3. **叙事节奏检查**：复用 `nc-节奏` 输出作为其中一模块
4. **五感信息均衡**：全程只有视觉缺听觉/触觉，或感官堆砌过载
5. **角色动机审计**：行为与当前情绪/欲望/立场/秘密是否匹配；标记无动机、行为割裂的桥段
6. **文本表层（可选开关）**：人设对话 OOC、用词前后不统一、重复冗余；只标记不润色

#### Scenario: 伏笔回收矛盾
- **WHEN** fs-xxx 声明 payoff_chapter 为第 20 章，但第 12 章节点已提前揭示该信息
- **THEN** 校阅意见书列出「伏笔回收过早：fs-xxx 于第 12 章泄露，早于声明的第 20 章」

### Requirement: nc-节奏 滑动窗口扫描

`nc-节奏` SHALL 以 `index/card-graph.json` 森林 + metric 指标 + 桥段绑定章节为数据源，做滑动窗口扫描（桥段数、伏笔释放数、信息载荷、爆点密度），识别两类异常：**过密**（短区间大量爆点反转→建议插留白/过渡桥段）、**过疏**（长区间无信息增量→建议补细节/微调节奏）。

豁免规则（自动识别）：`strategic-burst` 战略级爆发点跳过「过密」告警；`blank-transition` 留白过渡章节跳过「过疏」告警。触发方式：手动执行；或新增 3 个以上桥段绑定同一章节区间时自动提示。输出：节奏评估报告 + `rt-xxxx.json` 快照，只给建议。

#### Scenario: 战略爆点豁免
- **WHEN** 第 30 章被标注为 strategic-burst（全书高潮），该章密集排布 5 个爆点
- **THEN** `nc-节奏` 不对该章发出「过密」告警

#### Scenario: 自动提示
- **WHEN** 作者连续把 4 个新桥段都绑定到第 8~9 章区间
- **THEN** skill 主动提示「该区间桥段密度偏高，建议运行 nc-节奏 检查」

### Requirement: nc-守卫 合规与隐私扫描

`nc-守卫`（低频，分发前使用，默认隐藏，`enable_safety_guard: false` 默认关闭）SHALL 基于 `registry/safety-blacklist.yaml` 执行两大清单扫描：

1. **强制合规禁区（系统内置，不可删除，判定为模式识别而非关键词封杀）**：禁止对儿童色情、性剥削、暴力虐待进行细致感官化描写、美化、享乐化、教唆实施；**豁免**（降级为提示不判红线）：以纪实、调查、批判、揭露、普法为目的，用于控诉罪恶、剖析犯罪事件的内容
2. **作者自定义隐私禁区（可增删）**：公司全称/项目代号/工位、家庭住址/小区/楼栋、本人/家人健康病史、可交叉推理定位的碎片组合信息

匹配规则：精确词匹配 + 关联推理检测（多个单独无害的信息同时出现→可定位本人→告警）。告警分级：🔴 高风险红线 / 🟠 隐私命中 / 🟡 推理聚合风险。输出：`reflections/safety-check/sg-xxx.md` + `.json`；只告警，绝不自动删除/修改。触发时机：写稿完成后、nc-review 前；或 nc-export 对外分发前（最常用）。

#### Scenario: 揭露批判豁免
- **WHEN** 作品章节以纪实批判视角剖析某起真实犯罪事件
- **THEN** 守卫将其判定为「揭露批判」类别，降级为 🟡 提示而非 🔴 红线

#### Scenario: 隐私聚合告警
- **WHEN** 文中分散出现「某园区 7 号楼」+「心内科住院部」+「周三值班」三条单独无害信息
- **THEN** 守卫触发关联推理检测，输出 🟡 推理聚合风险告警
