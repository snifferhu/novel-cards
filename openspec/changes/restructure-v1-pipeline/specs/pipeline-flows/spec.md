# Spec Delta

## Purpose

定义 novel-cards 的三大场景流程（从零原创写作 / 外部作品对标拆解 / 纯素材整理）的技能编排顺序，长短篇分级（short/mid/long）对技能启用集的过滤规则，写稿→审稿→修稿→定稿的分支开关机制，以及 2026-10-23 追加的 `nc-研判`（单点创作推演）/ `nc-编排`（批量「计划→审核→执行」三段式）在流程中的位置与角色动向标尺随桥段推进的长期弧光链路。

## ADDED Requirements

### Requirement: 场景一 原创写作流程

从零创作原创故事的主流程 SHALL 按以下顺序编排（标注「可选」的节点可跳过）：

1. 【可选】`nc-素材`：灵感/参考素材/设定草稿入库 →（素材杂乱才走）`nc-清洗` →（可选）`nc-检索` 查找可复用资产；【备选】`nc-注册` 新增自定义类型/动线标签
2. 搭建叙事单元（多选并行，不分严格先后）：`nc-角色`（人/蛤蟆/器灵等行动单元）、`nc-道具`（黑盒三层）、`nc-场景`；【游离备选】`nc-姿态` 招牌动作库
3. `nc-桥段`：搭建剧情单元、绑定角色/道具/pose、标记章节、标注战略爆点；长篇开启时并行：`nc-伏笔` / `nc-快照` / `nc-势力` / `nc-暗线`；【游离备选】`nc-动向` 为角色建性格/心智倾向滑动标尺卡（`tend-*`，每次变动绑定本步新增的桥段作为推手，刻画渐进弧光）
4. `nc-积木`：编排联动（动线、伏笔、pose 触发关系组装）；【备选】`nc-量化` 挂载张力/信息载荷指标
5. `nc-图谱`：渲染叙事森林/时序/关系链路图自查逻辑
6. `nc-成稿`(nc-draft)：读取已备好的设定/桥段/大纲/暗线/角色等卡片，按 `--length short/mid/long` 控制篇幅，自动生成正文初稿（走提案制，作者校阅后落盘→manuscript/）；`nc-词频`(nc-wordfreq) 提供词频向量+感官均衡约束（纯约束校验，不出正文），为成稿提供约束输入
7. 【写稿完成后】`nc-校阅`：叙事审计（内置调用 `nc-节奏` 输出作为节奏模块；含 character_tendency 动向逻辑冲突检查项）
8. 【对外分发才走】`nc-守卫`：隐私+合规扫描（低频）
9. 【可选】`nc-定稿`：工程整体快照归档、锁定版本
10. 【需导出才走】`nc-导出`：输出 Word/PDF
11. `nc-复盘`：沉淀洞察、回流素材库，回到检索开启新一轮构思

**创作迭代分支（2026-10-23 追加）**——当已有资产需要局部微调或批量迭代时，从主流程分叉出两个按需工具，均不进入强制主线：

- **单点推演**：`nc-研判`(nc-analyze) 读取选定的桥段/角色动向/感官标记资产 + 作者诉求，输出多方案 A/B/C 建议报告（只出不改）；作者选定方案后调用对应专项技能（`nc-动向`/`nc-桥段`/`nc-感官标记`）落地，再回 `nc-校阅` 查冲突。
- **批量迭代**：`nc-编排`(nc-compose) 根据素材/原有剧情资产/情节目标生成结构化编排计划（create_plot/edit_plot/archive_plot/update_tendency/bind_sensory_cue 四类任务），交作者逐条审核增删改；审核定稿后**前置自动跑 `nc-校阅` 扫整套计划叠加冲突**，无红色冲突才顺序执行（每步调底层技能并记 CHANGELOG），遇冲突暂停退回计划页。

#### Scenario: 短篇快速路径
- **WHEN** short 模式作者只想写个 2 万字单主线故事
- **THEN** 流程推荐列表自动过滤掉 nc-伏笔/nc-势力/nc-暗线/nc-快照/nc-量化/nc-对标/校阅/定稿/导出，只保留素材/清洗/检索/角色/桥段/道具/场景/积木/成稿(--length short)/词频(可选)/复盘/简易节奏；nc-研判/nc-编排 作为迭代分支工具在 short 下默认不主动推荐（按需手动触发）

#### Scenario: 角色弧光随桥段推进
- **WHEN** 长篇作者为某主角建了 `tend-*` 动向标尺（克制↔放荡），后续每章新增桥段推动刻度滑动
- **THEN** 每次 `nc-桥段` 落地新事件后，`nc-动向` 追加一条 `history[]`（绑定该桥段 id）；`nc-校阅` 校验刻度变化是否符合 `direction_rule` 长期趋势

### Requirement: nc-编排 计划→审核→执行三段式分支

`nc-编排`(nc-compose) SHALL 作为批量剧情迭代的独立分支，遵循严格三段式：① 生成结构化编排计划（4 类任务清单，每条含预览/预期影响/风险提示）；② 交作者逐条审核（同意/编辑/移除/新增自定义任务/整体约束如「单次变动最多 +1」）；③ 作者确认【计划定稿开始执行】后，MUST 前置自动跑一次 `nc-校阅` 扫描整套计划叠加后的冲突，无严重冲突才顺序执行（每步调用对应底层技能并记录 CHANGELOG、更新 latest.md），遇红色冲突暂停退回计划页让作者调整，绝不强行执行。计划文件 MUST 保存为素材（`tag:compose-plan`）。全程禁止静默修改任何 cards/正文。

#### Scenario: 批量扩写执行
- **WHEN** 作者审核完 compose_plan 点击【提交执行】
- **THEN** skill 先跑 nc-校阅 扫全套任务叠加冲突；无红冲突则按 t01→t05 顺序逐条调 nc-桥段/nc-动向/nc-感官标记 落地，每步记 CHANGELOG；中途遇红冲突暂停定位到冲突任务

#### Scenario: 整体约束生效
- **WHEN** 作者在审核面板添加整体约束「禁止大幅跳动角色刻度，单次变动最多 +1」
- **THEN** 执行阶段所有 update_tendency 任务的 delta 被钳制在 ±1 内，超出的任务退回计划页

### Requirement: 场景二 对标拆解流程

拆解分析现成外部作品的流程 SHALL 为：`nc-素材`（原作原文/截图转写/摘抄入库）→（OCR/网页素材必走）`nc-清洗` → `nc-检索`（避免重复建卡）→ `nc-对标`（创建作品总档案）→ 并行建卡（`nc-角色` / `nc-道具` / `nc-场景` / `nc-伏笔` 梳理回收链 / `nc-快照` 按章节切片 / `nc-暗线` 梳理隐秘主线与信息差）→ `nc-桥段`（原作剧情拆成桥段单元）→ `nc-积木`（梳理触发逻辑与因果链）→ `nc-量化`（统计节奏/张力/信息投放）→ `nc-图谱`（时序图/关系图）→ `nc-校阅`（复核理解偏差）→ `nc-复盘`（总结套路沉淀进素材供后续创作复用）。

#### Scenario: 对标一部网文
- **WHEN** 作者想拆解某部网文的伏笔回收手法
- **THEN** 按场景二流程执行，拆解产物全部带独立 tree_id 存于 card-graph.json 森林，与原创主线隔离

### Requirement: 场景三 纯素材整理

单纯素材整理（只存资料不写故事）的流程 SHALL 为：`nc-素材`（原始文本入库原样留底）→（杂乱素材）`nc-清洗`（降噪生成干净副本）→ `nc-检索`（随时调取）。不需要走角色/桥段等创作类技能。

#### Scenario: 只囤素材
- **WHEN** 作者处于收集期，只丢链接和摘抄
- **THEN** 仅执行素材/清洗/检索三技能，不触发任何建卡引导

### Requirement: 长短篇分级配置

全局配置存放于 `registry/work-length-config.yaml`；新建工程选定 mode 后，流程推荐列表 MUST 自动过滤掉该模式下关闭的技能：

- **short**（≤3万，单主线少量角色）：默认启用 素材/清洗/检索/角色/桥段/道具/场景/积木/成稿(--length short)/复盘/简易节奏（词频可选）；默认关闭 nc-注册复杂track、nc-伏笔、nc-势力、nc-暗线、nc-快照、nc-量化、nc-对标、多树森林图谱、校阅/定稿/导出（手动开才可用）
- **mid**（3~15万，主线+少量支线）：短篇全套 + nc-伏笔、nc-快照、完整节奏、基础量化、基础图谱；默认关闭 nc-势力、nc-暗线、快照状态、多独立叙事森林、大规模对标
- **long**（>15万，多支线多势力）：全部技能全开，无默认关闭

短篇用户默认看不到复杂长线建模技能，不被大量概念压垮；长篇解锁全部能力。

#### Scenario: mid 模式推荐
- **WHEN** 工程配置为 mid 模式
- **THEN** 完成 nc-桥段 后的下一步推荐包含 nc-伏笔 与 nc-快照，但不主动推荐 nc-势力/nc-暗线

### Requirement: 写稿审稿修稿定稿分支开关

配置 MUST 存放于 `registry/work-setting.yaml`：`pipeline_option.enable_review`（是否开启审稿）、`pipeline_option.enable_finalize`（是否开启定稿锁定）。子流程顺序 SHALL 为：写稿（`nc-成稿` 读全部卡片出正文初稿→提案→作者校阅落盘 manuscript/；`nc-词频` 提供词频向量+感官均衡约束作为输入）→【enable_review=true 时】审稿（`nc-review` 产出意见不改原文→reflections/review-notes/）→修稿（作者对照意见自行改 md 手稿与底层卡片，改完可重跑 nc-节奏/nc-校阅）→【enable_finalize=true 时】定稿（`nc-finalize` 资产快照归档打 final 标签；关闭则修改无锁随时迭代）。私人创作场景（review=false、finalize=false）SHALL 在写稿完成后直接推荐 nc-复盘回流。

#### Scenario: 自娱模式
- **WHEN** `enable_review: false` 且 `enable_finalize: false`
- **THEN** 写稿完成后流程直接推荐 nc-复盘，跳过审稿与定稿两步
