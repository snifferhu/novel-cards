# nc - 初始化提案：适配你的长篇写作工程（novel-cards 卡片体系）

>

素材方向：**以情欲外壳为渡船，内核承载社会学、权力叙事、认知思辨的长篇**

3. 独家洞察：你的核心坐标「假去真来真胜假、坐标＞通道、叙事收割机制」是贯穿全书独有的锚点 ✅

7. nc - 图谱：渲染联动总图，可视化校验积木联动逻辑，检查爆点时序有没有错位
8. 写作阶段：以 lx 词频卡控制用词疏密，以 md 模块作为描写骨架，不随便加感官描写；该留白的地方严格遵循 blank_rule
9. 写完章节：nc - 复盘，生成 rf 反思卡
   - stuck：词频失控？感官堆砌？联动没生效？

10. 回流：新萃取的表达，补充进 co 语料卡，进入下一轮循环

## 六、硬规则补充（hard-rules.md 追加）

1. 所有跨动线同步变化，**必须走 module 积木模块，禁止在正文或者动线卡里零散写联动**；保证所有感官变化可追溯、可提前编排
2. 长线道具 / 感官爆点，要求：伏笔 fs 卡、动线 tl 节点、模块 md、词频 lx 四方对齐，提前≥8 章预埋（满足你提前十几章铺道具动线的需求）
3. 词频张力卡是强约束：爆点段落高密词集中释放；爆点之后强制留白，禁止持续堆叠感官描写
4. 多视角装造视图，必须写在 module 模块内，不混入正文、不混入动线时序
5. 通胀过滤器依然前置：新语料、新桥段，先 nc - 过滤，判断是否具备独家洞察，同质化素材打入 drafts/practice

# 合规规则最终锁定

核心准则：

1. 拿到 URL，优先读取目标站点 `robots.txt`。只要 `robots.txt` 里对该路径标记为禁止抓取（Disallow），**直接拦截，不发起页面请求**，直接提示作者。
2. 就算 `robots.txt` 没明确禁止、页面本身可以静态抓取，抓取成功后依然固定附带版权提醒，告知仅限个人创作参考、自行承担使用责任。
3. 不尝试任何绕过 `robots.txt`、反爬、登录校验的手段；遇到动态 JS、鉴权、反爬、robots 禁止，全部终止抓取流程，不重试。
4. 定位重申：**这不是爬虫，只是单点自用摘录工具；不批量、不商用、不突破站点声明规则**。

三、核心概念定稿
nc-角色（actor）—— 不只是人
定义：拥有独立主观视角、可参与桥段、可绑定感知/抽象动线、具备状态变化的叙事行动单元，和是否人类无关。
分类标签（frontmatter 打标，不锁死）：protagonist 主角 / supporting 配角 / extra 路人 / creature 生灵(蛤蟆·异兽) / object-spirit 器物灵体(会跑的桌子·宝剑器灵) / force 抽象意志 / phantom 幻影残魂
与道具区分：
actor = 主动，能发起动作、有主观感知、有欲望动机
item = 默认被动；一旦拥有独立意志主动行动，应建模为 actor，道具卡保留物理本体，两者 cross_ref 互相引用。
nc-道具（item）—— 黑盒三层建模
作者只需自然描述道具，无需知道底层分层；黑盒内部自动拆解并写入图森林。
内部三层：
物理层：材质、尺寸、耐久、限制、使用条件、客观规则
感知层：五感映射（visual/auditory/olfactory/gustatory/tactile；玄幻灵觉归入五感子标签）
抽象非感知层：绑定权力、秘密、记忆、宿命、信任等抽象 timeline，道具作为符号载体
高级模式开关：打开后展示三层分区，允许手动调整感知 track 绑定（深度拆解、作品量化用）。
感知体系公理 —— 五感为根，玄幻灵觉是变体
人类原生五感：视觉 / 听觉 / 嗅觉 / 味觉 / 触觉(温·压·痛·肌理)
玄幻衍生感知 = 五感的模拟、组合、超距变种（不新增脱离五感底层的独立感知大类）
  灵识/神念扫描   → 触觉 + 回声定位（雷达·声呐型探测）
  神视/天眼      → 视觉延伸（穿透·望远·透视·多波段）
  灵嗅/辨息      → 嗅觉超距高分率版
  灵味/道韵尝感  → 味觉抽象化
  神魂刺痛/震颤   → 触觉(痛觉/压力)投射到精神层面

感知动线根只能落在五感之一；玄幻能力只是子标签。
非感知抽象动线（权力/秘密/记忆/欲望/宿命/张力/信任）与感知动线平行，互不侵占，可自由注册扩展。
nc-快照（snapshot）—— 时间锚点状态切片
❌ 不是：姿势库、插画、动态素材库。
✅ 定义：在某确定章节/时间锚点上，一套锁定的、瞬时的全局状态切片；可单聚焦 actor，也可定格场景内多方角色/道具/势力/动线状态。
用途：前后对比、校验逻辑（"这一刻角色知不知道秘密？伤势多重？手里拿着什么？"）。
与 timeline 区别：timeline = 变化过程（曲线）；snapshot = 时间轴上钉点，拍下此刻所有变量值。
快照内可用字段：used_pose 引用姿态；校阅时校验「此刻状态能否支撑该 pose」。
nc-姿态（pose）—— 招牌动作库（解决跨场景复用一致性）
一个 pose = 【固定内核（招牌不变） + 环境变量插槽（每次调用替换） + 多视角文案 + 使用约束】
内核锁死不改，保证辨识度统一；插槽随环境/伤势/情绪变化，适配场景，不出戏。
pose_tag：signature 招牌 / habit 习惯性小动作 / combat 战斗 / relax 休憩 / special 专属秘术变身
存放：cards/pose-bank/po-xxx.md
插槽填充机制（3 层优先级）
桥段本地手动覆写(slot_override)  >  当前时间锚点快照状态(自动填充)  >  pose默认兜底(slot_default)

优先级1：桥段卡片引用 pose 时局部赋值，覆盖一切自动值。
优先级2（默认）：桥段绑定快照，自动读取快照里的伤势/情绪/环境填入插槽，作者零填写，全章统一。
优先级3：未绑定快照（短篇常见）时，用 pose 的 slot_default 兜底。
填充后跑 extra_constraint 校验（如"水下不可鼓腮"），冲突进 nc-review 意见，不自动改文字。
黑盒模式：作者只写"蛤蟆主角用招牌戒备 pose po-001"，系统自动拉快照填插槽、渲染多视角、跑校验。
高级模式：手动改单个插槽，其余沿用快照自动值。
nc-桥段（plot）+ nc-积木（module）
桥段：剧情单元，绑定角色/道具/pose、标记章节、标注是否战略爆点。
积木：最小调度单元，trigger_map 可自由绑定任意数量、任意 track 类型的 timeline 节点 + 自定义类型卡片（symbol/metric）+ pose；不锁死固定四感。

子流程顺序：
写稿：nc-词频 辅助，产出手稿 → manuscript/
【可选】审稿：nc-review 产出意见，不改原文 → reflections/review-notes/
修稿：作者对照意见自行改 md 手稿、改底层卡片；改完可重跑 nc-节奏 / nc-校阅
【可选】定稿：nc-finalize 做资产快照归档，打 final 标签；关闭则修改无锁，随时迭代
私人创作场景：review=false，finalize=false，写完直接到复盘回流，砍掉审稿定稿两步。
七、nc-review 校阅维度（只出意见，不改稿）
设定一致性审计（最高优先级）：角色/道具/pose 定义与桥段、快照使用是否冲突；世界观、势力、玄幻规则是否自洽
动线与状态链路审计：感知/抽象动线前后状态跳变无过渡；伏笔丢失/回收太早太晚/逻辑矛盾；角色获取信息是否合理
叙事节奏检查：复用 nc-rhythm 输出，作为其中一模块
五感信息均衡：全程只有视觉、缺听觉/触觉；或感官堆砌过载
角色动机审计：行为与当前情绪/欲望/立场/秘密是否匹配；标记无动机、行为割裂的桥段
文本表层（可选开关）：人设对话 OOC、用词前后不统一、重复冗余；只标记，不润色
输出：review-xxx.md（可读意见书） + review-xxx.json（结构化清单）。

八、nc-safetyguard 守卫（低频，分发前用，默认隐藏）
存储：registry/safety-blacklist.yaml（工程级）
两大清单：
强制合规禁区（系统内置，不可删除，但判定是模式识别非关键词封杀）：
禁止：对儿童色情、性剥削、暴力虐待进行细致感官化描写、美化、享乐化、教唆实施
豁免（降级为提示，不判红线）：纪实、调查、批判、揭露、普法为目的，用于控诉罪恶、剖析犯罪事件（如写"萝莉岛事件"做揭露批判）
作者自定义隐私禁区（可增删）：公司全称/项目代号/工位、家庭住址/小区/楼栋、本人/家人健康病史、可交叉推理定位的碎片组合信息
匹配规则：精确词匹配 + 关联推理检测（多个单独无害的信息同时出现 → 可定位本人 → 告警）
告警分级：🔴 高风险红线 / 🟠 隐私命中 / 🟡 推理聚合风险
输出：reflections/safety-check/ sg-xxx.md + .json；只告警，绝不自动删除/修改。
触发时机：写稿完成后、nc-review 前；或 nc-export 对外分发前（最常用）。
配置：enable_safety_guard: false（默认关闭，需要时手动打开）。

九、nc-rhythm 节奏校验（游离辅助）
数据源：card-graph.json 森林 + metric 指标 + 桥段绑定章节。
滑动窗口扫描：桥段数、伏笔释放数、信息载荷、爆点密度。
识别两类异常：
过密：短区间大量爆点反转 → 建议插留白/过渡桥段
过疏：长区间无信息增量 → 建议补细节/微调节奏
豁免规则（自动识别）：strategic-burst 战略级爆发点跳过"过密"告警；blank-transition 留白过渡章节跳过"过疏"告警。
触发：手动执行；或新增 3 个以上桥段绑定同一章节区间时自动提示。
输出：节奏评估报告 + rt-xxxx.json 快照，只给建议。

## 补充两条规则写入顶层规范

1. `agents.md` 是**引导提示，不是强制锁死**，作者可以手动编辑这份文件，自己增删意图匹配规则、自定义话术；
2. 当作者明确写出 `nc-xxx` 指令时，**优先执行指令，不再触发意图猜测和技能推荐**；意图识别只在没有指令、自由碎输入的时候生效。
