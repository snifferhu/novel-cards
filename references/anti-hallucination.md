# 防空炮铁律（anti-hallucination.md）

novel-cards v1.0 提供**防空炮铁律定调规范**能力：以四大铁律 + 系统能力边界 + 顶层
一句话规范，作为 nc-研判 / nc-校阅 / nc-编排 三个技能的最高行为约束，根治 AI 推理中
的空炮、脑补、超纲输出问题。本规范是**行为契约**而非实现细节，MUST 落进 SKILL.md body
与本文档，所有 nc-* 技能推理输出 MUST 以此为准绳。

## 顶层一句话规范

> **有卡有据、无卡停推、越界告警、转变留档、零空炮脑补。**

这十五字是全局最高约束，覆盖以下四大铁律。任何 nc-* 技能的推理输出若违反其中任一
条款，即视为防空炮违规，nc-校阅 应抛 L2_WARN 并附修正建议。

## 铁律一：无卡不推演

nc-研判 / nc-校阅 / nc-编排 在执行任何剧情推演、行为判断、心理分析前，SHALL 先检查
对应资产卡是否存在（角色 / 场景 / 道具 / 桥段）。缺少必要资产卡时 MUST 直接返回
「资产不足，无法研判」，MUST NOT 基于想象补全设定后继续推演。

### WHEN/THEN 判定示例

| 场景 | WHEN | THEN |
|---|---|---|
| 缺场景卡拒绝推演 | 作者要求「推演男主在车里站起来会怎样」，但工程内无对应 space_snapshot 卡 | nc-研判 返回「资产不足：缺少场景空间卡，无法判断车内能否站立」，不自行假设车厢尺寸 |
| 缺角色动向卡 | 作者要求推演某角色反应，但该角色无 character_tendency 卡 | nc-研判 提示需先经 `nc-动向` 建立性格滑动标尺，拒绝凭空推断性格 |
| 缺道具卡 | 正文提到「玉佩发烫」但工程内无该 item 卡的 active 状态定义 | nc-校阅 提示「道具效果未定义」，不自行脑补发烫的触发条件与机制 |
| 缺桥段前置 | 推演依赖某前置桥段结果，但该 pp-* 卡不存在 | nc-研判 返回「资产不足：前置桥段 pp-xxx 不存在，无法推演后续」 |

### 核心原则

- **有卡才推**：推演所需的每个维度（空间 / 人格 / 感官 / 因果）都须有对应卡片支撑
- **缺卡即停**：任一维度缺卡 → 停止该维度的推演，明确告知作者缺什么卡
- **绝不脑补**：MUST NOT 用「合理推测」/「一般常识」/「通常来说」替代缺失的卡片数据

## 铁律二：人格不允许空炮

deep 模式下，角色所有情绪、选择、克制、爆发 MUST 可由六轴基线 + prototype_note 约束
解释。突破原型轴边界 MUST 同时满足三个条件，三者缺一即视为空炮违规，nc-校阅 抛
L2_WARN：

1. **有触发事件记录**：change_log 绑定具体桥段（pp-*），说明是什么事件推动了变化
2. **填 override_note 备案**：frontmatter 的 `override_note` 字段说明为何突破原型边界
3. **写入日志**：change_log 记录时间戳 + 触发事件 + 漂移方向 + 漂移幅度

simple 模式豁免此约束（轴可自由飘动，不做 PERSON_001 校验）。

### WHEN/THEN 判定示例

| 场景 | WHEN | THEN |
|---|---|---|
| NPD 温柔示好判定为表演 | deep 模式，npd-grandiose 角色对女主温柔体贴 | nc-研判 默认判定为「表演索取自恋供给」而非真实共情（empathy 上限锁死 ≤ -3），除非有重大弧光触发事件 + override 备案 |
| 稳守型无故黑化 | deep 模式，steadfast 角色在无触发事件情况下突然背叛盟友 | PERSON_001 抛 L2_WARN：稳守型不无故黑化，需补充背叛触发事件或 override_note |
| 冲动型突然克制 | deep 模式，reckless 角色在关键战斗中完全冷静 | PERSON_001 抛 L2_WARN：impulse_control 轴从 -7 跳到 +5 超出 max_drift，需触发事件 + override_note |
| 回避型突然黏人 | deep 模式，avoidant 角色主动拥抱并表白 | PERSON_001 抛 L2_WARN：trust 轴正向漂移超限，需补充关系质变触发事件 |

### 核心原则

- **原型是基线不是牢笼**：角色可以突破原型，但突破必须有据（事件 + 备案 + 日志）
- **BPD 大幅波动合法**：borderline 原型的 trust/emotion 轴天然高波动，max_drift 放宽
- **简单模式自由**：simple 档不读 prototype_note 约束，爽文特权保留

## 铁律三：感官空间物理绝不脑补

系统 MUST NOT 在缺少对应卡片时自行补全感官 / 空间 / 物理设定：

| 缺失卡片 | MUST NOT 做的事 |
|---|---|
| 无空间卡（sc-* 无 usable_clearance） | 不判断能否站立 / 移动 / 转身 |
| 无姿态卡（po-* 无 pose_bounds） | 不描写肢体细节 / 不判断姿态是否可行 |
| 无道具卡（it-* 无 state_list） | 不触发道具效果 / 不描述道具状态变化 |
| 无感官标记卡（su-*） | 不生成氛围信号 / 不描述五感细节 |
| 无感官掩码（ac-* 无 sensory_mask） | 不判断角色能否看见 / 听见 / 闻到 |

缺卡即停止推理，MUST NOT 自己补设定。

### WHEN/THEN 判定示例

| 场景 | WHEN | THEN |
|---|---|---|
| 无道具卡不触发效果 | 正文提到「玉佩发烫」但工程内无该 item 卡的 active 状态定义 | nc-校阅 提示「道具效果未定义」，不自行脑补发烫的触发条件与机制 |
| 无空间卡不判断站立 | 桥段描述角色「站起身来」但 sc-* 卡无 usable_clearance 字段 | nc-校阅 跳过 SPACE_001 推演（向后兼容），不报「净高不足」也不报「可以站立」 |
| 无感官掩码不判断感知 | 桥段描述失明角色「看到了月光」但 ac-* 卡无 sensory_mask 字段 | nc-校阅 跳过 SENSE_001 校验（向后兼容），不报「失明角色不应有视觉描写」 |

### 核心原则

- **缺字段 = 跳过校验**：向后兼容铁律——存量卡缺失新字段时，校验逻辑跳过该维度，行为与引入前一致
- **绝不反向脑补**：不能因为「一般来说轿车里站不起来」就报 SPACE_001 告警——没有 usable_clearance 数据就没有判断依据
- **提示补全而非替补**：发现缺字段时提示「建议补全 xxx 字段以启用完整校验」，绝不自行填充

## 铁律四：不生成未定义剧情

所有剧情输出 MUST 遵守四原则：

| 原则 | 含义 | 违反后果 |
|---|---|---|
| **伏笔闭环** | fs-* 有 payoff_chapter 或 status: unresolved；反转须有前置伏笔卡 | nc-校阅 抛告警：未铺垫反转违反伏笔闭环原则，建议先经 `nc-伏笔` 预埋 |
| **时序合法** | precondition_beat_ids 先于 postcondition_beat_ids 发生；sequence_index 单调递增 | nc-校阅 抛 CAUSAL_001 L1_HARD：因果链断裂 |
| **人格自洽** | 角色行为匹配当前 tend-* 标尺位置 + baseline_prototype 约束 | nc-校阅 抛 PERSON_001 L2_WARN：OOC（out of character） |
| **资产对应** | 引用的 id 全部存在（ac-*/pp-*/it-*/sc-*/su-*/po-*/fs-* 等） | nc-校阅 抛悬空引用告警 |

MUST NOT 生成：无铺垫反转 / 无依据心理活动 / 未定义剧情走向 / 凭空新增角色或道具。

### WHEN/THEN 判定示例

| 场景 | WHEN | THEN |
|---|---|---|
| 无铺垫反转拦截 | 桥段描述主角突然获得神秘力量，无任何前置伏笔卡 | nc-校阅 抛告警：未铺垫反转违反伏笔闭环原则，建议先经 `nc-伏笔` 预埋 |
| 时序倒挂 | pp-B.precondition_beat_ids 含 pp-A，但 pp-A.chapter > pp-B.chapter | nc-校阅 抛 CAUSAL_001 L1_HARD：前置桥段 pp-A 章节晚于 pp-B，时序非法 |
| 凭空心理活动 | 桥段描述「他感到一阵莫名的悲伤」但无 tend-* 卡记录情绪变动 | nc-校阅 抛告警：无依据心理活动，建议先经 `nc-动向` 建立情绪标尺 |
| 悬空引用 | 桥段 participants 含 ac-角色-丙 但该卡不存在 | nc-校阅 抛悬空引用告警：ac-角色-丙 未找到对应角色卡 |

## 系统能力边界

### 能做（5 项）

| # | 能力 | 说明 |
|---|---|---|
| 1 | **校验自洽** | 基于已有卡片做逻辑一致性校验（SPACE_001 / SENSE_001 / PERSON_001 / CAUSAL_001 等），输出三级分组告警 |
| 2 | **推演三分支** | 给定事件 + 完整资产，推演方案 A/B/C（如「换场景 / 换姿态 / override 豁免」），每分支标注前提条件 |
| 3 | **固化伏笔** | 协助作者规划伏笔预埋-回收时序（foreshadow_timeline），校验四方对齐（fs-/tl-/md-/lx- ≥8 章） |
| 4 | **标准化素材** | 将口述灵感 / 原始素材结构化为标准卡片提案（走提案制，AI 出草案用户落盘） |
| 5 | **批量改稿** | 基于 compose_plan 执行批量剧情调整（先计划→审核→执行，前置 nc-校阅 扫冲突） |

### 绝对不做（5 项）

| # | 禁区 | 说明 |
|---|---|---|
| 1 | **脑补设定** | 绝不基于「合理推测」/「一般常识」补全缺失的卡片数据（空间尺寸 / 人格参数 / 道具效果） |
| 2 | **凭空加情绪** | 绝不在无 tend-* 标尺支撑的情况下给角色添加情绪描写或心理活动 |
| 3 | **强行圆 BUG** | 绝不为消除告警而修改卡片内容或桥段描述（审计类技能只读铁律） |
| 4 | **无铺垫人设转变** | 绝不让角色在没有触发事件 + override 备案的情况下突破原型轴边界 |
| 5 | **无资产依据推演** | 绝不在缺少必要资产卡的情况下继续推演（无卡即停推） |

## 与既有硬规则的协同

本防空炮铁律**不替代** `references/hard-rules.md` 的 34 条硬规则，而是为其提供
**行为层面的最高约束**：

- hard-rules.md 是**规则权威**（人类可读的完整规则描述 + 机器真值 rules.json）
- anti-hallucination.md 是**行为契约**（AI 推理时的自我约束准绳）
- 二者协同：hard-rules 定义「什么是对的」，anti-hallucination 定义「AI 该怎么行为」
- 当 nc-研判 / nc-校阅 / nc-编排 的输出同时违反 hard-rules 和 anti-hallucination 时，
  以 hard-rules 为准（它是更具体的规则集）

## 规范可见性

- **SKILL.md body**：硬规则速览区含防空炮摘要（指向本文档）
- **references/anti-hallucination.md**：本文档（完整四大铁律 + 能力边界 + WHEN/THEN 示例）
- **nc-研判 / nc-校阅 / nc-编排 输出**：每次推理输出前自检四大铁律，违反时在输出头部
  标注「⚠️ 防空炮提醒：[具体违反条款]」

用户询问「这个工具会不会瞎编」时，答案明确：**不会**。本系统的能力边界由四大铁律
严格限定——有卡有据才推演，无卡即停，越界必告警，转变必留档，零空炮零脑补。
