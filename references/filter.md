# 通胀过滤器（Inflation Filter）

> 系统每次吸收新素材时的入口 gate。作用是防止「人人都能讨论、别人三个月能做、
> 你没独家洞察」的低价值素材污染正式排期。

## 1. 为什么要过滤

素材是稀缺资源——作者的时间、灵感、素材库的容量都是。
不过滤的后果：素材库膨胀但产出效率不变，写作选题时面对一堆同质化素材无从下手，
读者看到的是「和谁谁谁写的一样」的内容。

过滤器的目标不是「把素材拒之门外」，而是**给每个素材一个明确的状态标签**：
「正式排期」或「练习稿」。两类素材都在库，但只有一类进入排期。

## 2. 触发时机

| 场景 | 是否触发 |
|---|---|
| 用户口述新素材 | ✅ 必须过 |
| 复盘卡反哺回来的新素材 | ✅ 必须过 |
| 用户明确说「这个先当练习稿」 | ❌ 跳过（用户已判定） |
| 更新已有卡片 | ❌ 不过（不是新素材） |
| 用户说「nc-过滤 一下」 | ✅ 手动触发 |

## 3. 三问

对每条新素材，AI 必须逐条问完这三问，并把答案与推理一并呈现给用户：

### Q1. 公共领域性
**「这个题材是否是公共领域人人都能讨论的？」**

- 若**是**（如：职场逆袭、校园霸凌、总裁文套路、穿越重生通用模板）：
  题材本身不产生排他性，需要靠角度或执行差异化。
- 若**否**（有明确的领域门槛、圈层门槛、专业门槛）：
  自带排他性，题材本身就是一种过滤。

### Q2. 三个月复刻性
**「如果我不做，三个月后会不会有别人用同样的角度做出来？」**

- 若**是**：角度不新鲜或已被市场充分占用，三个月内会被复制造到审美疲劳。
- 若**否**：角度稀缺或需要长期积累，短期内难以被复制。

### Q3. 独家洞察
**「我的角度里有没有只有我知道、只有我能提供的特殊经验或洞察？」**

这是最关键的一问。可能形态：
- **亲历经验**：作者真实经历、职业积累、圈层内部观察
- **知识密度**：需要跨领域综合、长期研究才能形成的判断
- **视角独特**：从别人没想到的位置切入
- **数据/案例独家**：只有作者手里的访谈、观察、内部信息

- 若**有**：这是护城河，值得投入正式排期。
- 若**没有**：素材只能贡献「练习感」，没有市场护城河。

## 4. 判定规则

| Q1 | Q2 | Q3 | 判定 | 去向 |
|---|---|---|---|---|
| 是 | 是 | 否 | ❌ 练习稿 | `drafts/practice/`，不进排期 |
| 是 | 是 | 是 | ⚠️ 需强化独家洞察 | 用户决定是否补料 |
| 是 | 否 | 是 | ✅ 可排期 | 进入正式素材池 |
| 否 | 是 | 否 | ⚠️ 门槛题材但无独家洞察 | 建议补独家洞察后再过 |
| 否 | 是 | 是 | ✅ 可排期 | 进入正式素材池 |
| 否 | 否 | 是 | ✅ 强推荐 | 优先排期 |
| 否 | 否 | 否 | ⚠️ 门槛在但无洞察 | 补独家洞察 |
| 任意 | 任意 | 否 | ❌ 练习稿（Q3 是否决项） | `drafts/practice/` |

**Q3 是否决项**：没有独家洞察的素材，无论题材多小众、多稀缺，都只能是练习稿。
因为写作最终比拼的是「你能提供的独家价值」，而不是「题材本身」。

## 5. 输出格式

AI 走完三问后，向用户输出如下格式的**提案**（不落盘）：

```
【通胀过滤器提案】素材：<摘要>

Q1 公共领域性：<是/否> — <一句话理由>
Q2 三个月复刻性：<是/否> — <一句话理由>
Q3 独家洞察：<有/无> — <一句话理由，若有需指出独家洞察形态>

判定：<练习稿 / 需强化 / 可排期 / 强推荐>
去向：<drafts/practice/ 或 素材池>

请确认：
(1) 同意此判定
(2) 补充独家洞察后重新评估
(3) 覆盖判定（用户强制排期，AI 需记录理由）
```

用户确认后才由用户落盘或推进到下一步。

## 6. 反例：什么不算「独家洞察」

以下形态**不**构成 Q3 的肯定答案，避免自我欺骗：

- 「我比别人更努力」— 努力不产生独家性
- 「我文笔更好」— 技法可训练，不构成护城河
- 「这个题材我很喜欢」— 喜好不等于稀缺
- 「我知道一些别人不知道的事」但无出处、无验证 — 需要具体证据

## 7. 与提案制的关系

过滤器本身遵守 skill 的提案制：

- AI **不写**素材文件、不写练习稿文件、不写反思卡的素材反哺条目
- AI 只输出「三问答案 + 判定 + 理由」的提案到对话
- 用户确认后，由用户自己决定落盘动作

## 8. 边界情况

- **判断错误怎么办**：过滤器是辅助，不是决策。用户可覆盖判定，但需记录理由。
- **同一素材多次过**：允许，每次记录 `created` 为最新评估日期。
- **素材被判定为练习稿后**：不进入正式排期，但保留在 `drafts/practice/`。
  后续若出现新独家洞察，可以重新评估升级。
